# RBF‑Solver

| Path | Brief Description |
|------|-------------------|
| **`rbf_solver.py`** | Core implementation of **RBF‑Solver**. |
| **`score_sde/`** | Complete pipeline for *CIFAR‑10* Score‑SDE experiments with integrated RBF‑Solver. |
| **`edm/`** | Complete pipeline for *CIFAR‑10* Elucidated Diffusion Model (EDM) experiments. |
| **`ddpm_and_guided-diffusion/`** | Complete pipeline for *ImageNet 64×64* Improved‑Diffusion (DDPM) experiments. |
| **`guided-diffusion/`** | Complete pipeline for *ImageNet 128×128* and *256×256* Guided‑Diffusion experiments. |
| **`stable-diffusion/`** | Complete pipeline for *Stable‑Diffusion v1.4* text‑to‑image experiments. |

> **Note:** Each sub‑directory contains its own README with step‑by‑step instructions for reproducing the results reported in the paper.
